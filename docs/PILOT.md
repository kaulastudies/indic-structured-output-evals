# Proposed paid pilot: multilingual integration regression gate

## Decision

Ready for a technical introduction and a paid scoping conversation. Not ready to claim a validated production partnership or proven model-quality improvement. We have two open upstream fixes, a runnable public checker and three bounded UI observations. We have no customer requirements, reviewed multilingual labels, raw API replication, agreed budget or evidence of willingness to pay.

## Offer

One customer-support extraction or classification workflow, English plus one customer-selected Indian language, delivered remotely in 10 working days after written scope and data access agreement. Rama Chandra M owns implementation and evidence; customer appoints a workflow owner; qualified language reviewer must be agreed and available before the multilingual evaluation begins.

Deliverables: versioned case inventory; agreed labels; reproducible baseline; one declared intervention; paired regression with held-out cases; ranked integration findings; handoff commands and an acceptance recommendation. No production deployment, speech evaluation, medical/legal decisions or live refund capability.

Planning target: 60 reviewed development cases and 20 held-out cases, two independent trials per case per baseline/intervention condition: 320 model calls. Counts are a proposed budget, not completed work. Customer approves representativeness, call/token caps and acceptable exact-output and semantic criteria before collection. Maximum 128 output tokens is appropriate only if the chosen workflow fits it; freeze the cap in the written scope.

## Success and stop criteria

Success means all planned cases have traceable records, failed/blocked calls are retained, relevant failure classes have useful reproductions, and the report measures regressions as well as improvements against predeclared criteria. Improvement is an experimental question, not a guarantee. Stop collection on authentication failure, exhausted credits or the agreed spend cap; do not retry blindly. Pause semantic claims if the reviewer is unavailable or labels are disputed. If no intervention helps, deliver that negative result.

## Commercial scope

This is a paid evaluation service proposal. Fee, payment milestones, reviewer budget and provider spend cap must be agreed in writing before work begins. No quote has been accepted, no work order exists and no improvement is guaranteed.

## Outreach threshold

A short introduction can ask whether this is a relevant paid evaluation need now. Raw API replication and independent case review are needed before selling an improvement claim or agreeing measurable model-quality guarantees. Do not make a broad partnership request or imply that contributions create entitlement to payment. Email draft is held privately; nothing has been sent.
